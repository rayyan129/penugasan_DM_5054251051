# Tugas 1 - Scraping & Eksplorasi Data (EDA)

Dataset diambil dengan scraping halaman Top Anime MyAnimeList
(https://myanimelist.net/topanime.php) menggunakan `requests` dan `BeautifulSoup`,
sebanyak 40 halaman = 2000 baris.

## Isi folder

| File | Keterangan |
|---|---|
| `5054251051_Rayyan_Muhtar_Ali_Tugas_Scrapping_dan_EDA.ipynb` | notebook scraping + EDA + laporan |
| `5054251051_Rayyan_Muhtar_Ali_Tugas_Scrapping_dan_EDA.pdf` | versi PDF dari notebook |
| `data_mentah_anime.csv` | hasil scraping mentah (2000 baris, 7 kolom) |
| `data_bersih_anime.csv` | data setelah kolom dipecah dan dikonversi (2000 baris, 12 kolom) |

## Library yang dipakai

```
requests beautifulsoup4 pandas numpy matplotlib seaborn
```
